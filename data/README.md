# Input data

Place the following five CSV files in `raw/` before running the analysis:

- `matbench-discovery-unique_prototypes.csv`
- `matbench-discovery-unique_prototypes_geo-opt.csv`
- `matbench-discovery-unique_prototypes-phonons.csv`
- `matbench-discovery-unique_prototypes-md.csv`
- `matbench-discovery-unique_prototypes-diatomics.csv`

The CSV files are intentionally excluded from Git. The local working copy was
copied unchanged from the original `bench_data/` directory. Before publishing
or redistributing them, confirm the upstream dataset license and add the
required citation and provenance information here.
